Необходимо разработать небольшую платформу с админкой для Media Defence Network of Kyrgyzstan. 

В схеме три страницы:
- Новости/Основная
- Тесты
- Профиль

Через админ панель можно будет удобно добавлять тесты, а также новости. Элементы на главной странице должны быть динамичны. 

Использую Docker, Docker-compose для деплоя.
Для написания проекта используй ReactTS, Golang.
